# DeAI 0.1.0 Preview 1

这是首个 macOS 试用版，供愿意手动安装和反馈问题的用户使用。应用版本为 0.1.0（build 1）。

下载 `DeAI-0.1.0-preview.1-macOS-universal.zip`，不要将 GitHub 自动生成的 Source code 压缩包当作安装包。另附 `SHA256SUMS.txt`，可在下载目录运行 `shasum -a 256 -c SHA256SUMS.txt` 核对文件。

## 安装与使用

1. 需要 macOS 14 或更新版本。包内包含 Apple Silicon 和 Intel 两种架构，不需要安装 Xcode 或 Rust。
2. 解压后，将完整的 `DeAI.app` 放入“应用程序”（`/Applications` 或 `~/Applications`），从这个固定位置打开。
3. 本包使用 ad-hoc（临时）签名，未经过 Apple 公证。如果提示无法验证开发者或 Apple 无法检查恶意软件，先确认下载来源可信、文件未被篡改，再按 [Apple 官方流程](https://support.apple.com/en-gb/102445)，在尝试打开后进入“系统设置 → 隐私与安全性 → 仍要打开”，并确认打开。若提示含恶意软件、会损坏电脑、文件损坏或签名异常，请停止安装并反馈，不要一律强行放行。
4. 在“系统设置 → 隐私与安全性 → 辅助功能”中添加并启用这个 `DeAI.app`。
5. 在 Word、文本编辑或备忘录中输入文字；点击下划线查看建议，点击采用才会修改正文。选中文字后可按 Control + Option + R 集中检查。

本地规则和英文语法检查不需要 API Key。AI 改写需在“设置 → AI 改写”中配置自己的模型服务；云端服务会收到改写内容。更新临时签名版本后，可能需要重新添加辅助功能授权。

## 当前范围

- 完整安装说明、数据流和源码构建方法见 [中文 README](https://github.com/YouAI-Liu/deai-writer/blob/main/README.zh-CN.md)。请在 Issues 中附系统和目标应用版本、复现步骤及不含私人信息的示例。

## English

This is the first macOS preview: app version 0.1.0, build 1. Download `DeAI-0.1.0-preview.1-macOS-universal.zip`, not GitHub's automatically generated source archive. Verify it with `shasum -a 256 -c SHA256SUMS.txt` in the download directory.

Requires macOS 14 or later. The app includes Apple Silicon and Intel binaries; Xcode and Rust are not needed. Extract the ZIP, move `DeAI.app` into `/Applications` or `~/Applications`, and keep that location when updating.

The app is ad-hoc signed and **not notarized**. For an unidentified-developer or cannot-check-for-malware alert, first verify that you trust the source and the file has not been altered. After attempting to open it, follow [Apple's instructions](https://support.apple.com/en-gb/102445): System Settings → Privacy & Security → Open Anyway, then confirm Open. Stop and contact the maintainer for malware, damage or signature-integrity warnings.

Enable the installed app in System Settings → Privacy & Security → Accessibility. Click an underline to inspect a suggestion, then accept it to change the text. Control + Option + R checks a selection. Local rules and English grammar checks need no API key. AI rewrite requires your own configured service; cloud services receive the rewrite text. An update may require granting Accessibility access again.

Word 16.113, TextEdit and Notes have been demonstrated. Browsers are not supported. A complete first-download-to-use test on another Mac, and separate first-install tests on both architectures, remain outstanding. See the [English README](https://github.com/YouAI-Liu/deai-writer/blob/main/README.md) for details.
